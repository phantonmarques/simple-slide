# Slide

Projeto simples de slide/carrossel de imagens, mantido como backup e referência. A proposta é resolver com JavaScript puro, sem frameworks e dependências.

## Como executar

Como o JavaScript usa módulos ES (`type="module"`), abra a página por um servidor HTTP local

No VS Code, inicie o **Live Server** na raiz do projeto. Como alternativa, com Python instalado, execute na raiz:

```bash
python -m http.server 8000
```

Depois, acesse <http://localhost:8000>.
